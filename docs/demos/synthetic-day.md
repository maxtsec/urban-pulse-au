# Synthetic city day

Open `http://127.0.0.1:5173/` after starting the web development server. This is the only product interface. Its moving content is an independent authored fixture and needs no API or database.

1. The page opens at simulated **Live**, starting at 10:00 on 8 October 2026. A red dot marks the live edge, which advances at 1× even while you browse history. Reload starts a new session.
2. Drag the slider or select an earlier two-hour block to enter **History**. Pause or play at up to 300× speed. The full-day strip remains visible, but future times are disabled. **LIVE** returns to the latest available time.
3. Switch to **3D** for teal trams, amber cranes and historical buildings. Zoom in to enlarge the models with the map; **Layers** controls visibility.
4. The fixed information panel opens on **Area health**: status and source coverage only, with no invented score. Use **Weather**, **Trams** and **Works** for details and keyboard selection. The panel has its own space and never covers map zoom controls.
5. Select 08:00–10:00 and move the slider: sunny changes to cloudy at 08:30 and rainy at 09:00. Weather history includes only readings at or before the selected time. Effects follow that clock; pause/seek is deterministic.
6. Reduced motion keeps discrete Live updates and manual history selection without autoplay. On mobile the information panel is a fixed-height row below the map, with internal scrolling.

Trams are **Simulated** on illustrative tracks. Each tram has an authored series of minute-spaced position samples; the two surrounding received samples determine its constant-speed path distance, displayed one minute behind the clock. The first minute holds the initial sample. Construction is **Illustrative** at authored locations; two sites are under construction and one is planned. Neither is a DAM observation or a real disruption. Sunny/cloudy/rainy readings are authored, not API forecasts. The only sourced map content is the existing Southbank boundary and historical City of Melbourne building context, credited in **Map credits**. All network assets are same-origin.

## Assets and checks

The three small, untextured glTF files are original project artwork generated by `scripts/build_demo_models.py`. Regenerate with `uv run python scripts/build_demo_models.py`; the checked-in bytes should be identical. No external model licence is required. The copied boundary must match `tests/fixtures/southbank.geojson` exactly, including its provenance.

From `apps/web`, run `npm run test:unit`, `npm run build`, and `npx playwright test tests/explorer.spec.ts`. The ordinary suite retains the original scenario coverage through `tests/scenario.html` in a separate `dist-test` build. The production build and Docker context exclude this harness. [ADR 0020](../adr/0020-synthetic-day-explorer.md) defines the preview's scope; implementation progress belongs to the [delivery plan](../delivery-plan.md).

See [visual and rendering evidence](../evidence/synthetic-day.md) for measured limits and reproduction.
