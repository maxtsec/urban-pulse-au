# Synthetic city day

Open `http://127.0.0.1:5173/?experience=day` after starting the web development server. This view needs no API or database; all moving content is an independent authored fixture. The existing `?scenario=city` walkthrough remains available through **Scenarios**.

1. The initial **History** window is 08:00–10:00 on 8 October 2026 in Melbourne. Press **Play**, choose a speed, or drag the time slider. Half-hour labels are equally spaced.
2. Select a two-hour block in the bottom strip to explore any part of the full 24-hour day. Playback stops at the chosen window's end; choose the next block to continue.
3. Switch to **3D** for teal tram models, amber cranes, planned-site blocks and historical building context. Use **Layers** to hide each component.
4. In the initial window, weather changes from sunny to cloudy at 08:30 and rainy at 09:00. Rain/cloud motion follows the clock; pausing or seeking remains deterministic. The summary always shows the authored condition even when its visual layer is hidden.
5. Select a summary card to see its short detail list. Keyboard-select a tram or project to highlight it on the map. Dismiss the panel to return to an uncluttered map.
6. **Live** follows a simulated latest time at 1×. The session starts at 08:00 when first entering Live; returning from History catches up to that session clock. It is not connected to provider data or the capture host. Reduced-motion users navigate with the time controls without autoplay.

Trams are **Simulated** on illustrative tracks. Construction is **Illustrative** at authored locations; two sites are under construction and one is planned. Neither is a DAM observation or a real disruption. Sunny/cloudy/rainy readings are authored, not API forecasts. The only sourced map content is the existing Southbank boundary and historical City of Melbourne building context, credited in **Map credits**. All network assets are same-origin.

## Assets and checks

The three small, untextured glTF files are original project artwork generated by `scripts/build_demo_models.py`. Regenerate with `uv run python scripts/build_demo_models.py`; the checked-in bytes should be identical. No external model licence is required. The copied boundary must match `tests/fixtures/southbank.geojson` exactly, including its provenance.

From `apps/web`, run `npm run test:unit`, `npm run build`, and `npx playwright test tests/explorer.spec.ts`. The ordinary suite retains the original scenario coverage. [ADR 0020](../adr/0020-synthetic-day-explorer.md) defines the preview's scope; implementation progress belongs to the [delivery plan](../delivery-plan.md).

See [visual and rendering evidence](../evidence/synthetic-day.md) for measured limits and reproduction.
