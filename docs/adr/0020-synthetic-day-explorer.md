# ADR 0020: Independent synthetic day explorer

Status: Accepted by the project architect on 2026-10-08 for the independent synthetic experience; implementation is reviewed separately.

## Decision

Use the full-day explorer as the sole public interface. Retain the existing 360-second scenarios only in a separate test harness, excluded from the production build. A deterministic authored day covers 00:00–24:00 Melbourne time, divided into twelve selectable two-hour windows. The initial view is simulated Live at 10:00, with the preceding two hours in the detail window. This is a presentation fixture, with no database writes, import generation change, provider calls or new public API.

History supports seeking, pause and 1×, 7.5×, 30×, 120× and 300× playback. Live follows a simulated 1× clock starting at 10:00 when the page opens, retained while visiting History in that page session. Reload restarts the demo session. Live is explicitly labelled synthetic; it does not suggest that the collector feeds this map. The full-day scale remains visible, but future blocks are disabled: History can only select times from midnight through the advancing live edge. The edge progresses independently while History is paused. A coloured LIVE signal marks the edge; Go live returns to it.

The map reuses the accepted MapLibre/deck.gl rendering stack. Original local glTF tram, crane and planned-site models have distinct colours; keyboard lists remain available. Sunny/cloudy/rainy are explicit synthetic weather states, not classifications inferred from missing precipitation. Weather effects and model geometry change no condition, warning, coverage or real-world counts. Construction is illustrative; planned projects use a static block model rather than a crane.

Trams use two minute-spaced synthetic samples and constant distance progression on illustrative fixture tracks, displayed one minute behind the synthetic clock. Before the second sample is received, the first position is held. The same integer-millisecond clock produces the same frame regardless of seek or playback history. Models, cloud drift and rain stop with the clock. Reduced motion starts in 2D, updates Live once per second without transitions, disables History autoplay and keeps manual selection available; 3D remains opt-in.

## Relationship to existing decisions

The architect requested these visual and playback changes together and accepted a separate synthetic fixture. This combined preview is separate from the per-item production acceptance in [ADR 0011](0011-southbank-building-massing.md). It does not implement or replace the accepted MAP-02 event, receipt, import, animation-endpoint or GTFS matching contracts, nor the production weather-source policy. Those integrations retain their existing gates and separate reviews.

The architect accepted a fixed information panel with Area health, Weather, Trams and Works tabs on 2026-10-08. Area health shows status and source coverage only; no numeric score or construction-to-health inference is introduced. Synthetic sources are marked Synthetic and real health is Not assessed. The panel occupies its own fixed-width column beside the map, with internal content scrolling; on narrow screens it occupies a fixed-height row below. Map controls never share its space. Translucent surfaces have an opaque fallback. A full-day strip selects a two-hour detail window with evenly spaced half-hour labels. Buildings retain their historical source credit; models are original project artwork generated by `scripts/build_demo_models.py`, with no downloaded third-party model assets. Model sizes use a fixed world-space scale for readability, so zooming in enlarges them naturally. They have no viewport-pixel size caps and are not physical measurements. Models render above building context to stay readable; this is an illustrative selection aid, not an occlusion/visibility analysis.

## Failure and verification

Load local uncompressed assets only. The build replaces the eagerly initialized meshopt WASM decoder with an explicit unsupported capability; compressed models fail into the existing static fallback. CSP remains unchanged. Missing models fall back to flat markers; missing building context is reported separately. WebGL loss hides map markers and recovery rebuilds the scene from the latest clock. A details list remains the accessible selection path. Test full-day boundaries, exact seek equivalence, weather transitions, view/layer selection, local asset requests, model failure, WebGL recovery and mobile layout. Measure the built view before considering performance acceptance. See the [walkthrough](../demos/synthetic-day.md) and [delivery plan](../delivery-plan.md).
