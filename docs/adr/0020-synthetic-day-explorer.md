# ADR 0020: Independent synthetic day explorer

Status: Accepted by the project architect on 2026-10-08 for the independent synthetic experience; implementation is reviewed separately.

## Decision

Add an opt-in `?experience=day` view alongside the existing 360-second city scenarios. A deterministic authored day covers 00:00–24:00 Melbourne time, divided into twelve selectable two-hour windows. The initial window is 08:00–10:00. This is a presentation fixture, with no database writes, import generation change, provider calls or new public API.

History supports seeking, pause and 1×, 7.5×, 30×, 120× and 300× playback. Live follows a simulated 1× clock starting at 08:00 on first entry to Live, retained while visiting History in that page session. Reload restarts the demo session. Live is explicitly labelled synthetic; it does not suggest that the collector feeds this map. History can explore the whole preauthored day.

The map reuses the accepted MapLibre/deck.gl rendering stack. Original local glTF tram, crane and planned-site models have distinct colours; keyboard lists remain available. Sunny/cloudy/rainy are explicit synthetic weather states, not classifications inferred from missing precipitation. Weather effects and model geometry change no condition, warning, coverage or real-world counts. Construction is illustrative; planned projects use a static block model rather than a crane.

Trams use two minute-spaced synthetic samples and constant distance progression on illustrative fixture tracks, displayed one minute behind the synthetic clock. Before the second sample is received, the first position is held. The same integer-millisecond clock produces the same frame regardless of seek or playback history. Models, cloud drift and rain stop with the clock. Reduced motion starts static 2D and keeps manual time selection available; 3D remains opt-in.

## Relationship to existing decisions

The architect requested these visual and playback changes together and accepted a separate synthetic fixture. This combined preview is separate from the per-item production acceptance in [ADR 0011](0011-southbank-building-massing.md). It does not implement or replace the accepted MAP-02 event, receipt, import, animation-endpoint or GTFS matching contracts, nor the production weather-source policy. Those integrations retain their existing gates and separate reviews.

The explorer has a compact summary, on-demand detail panels and translucent surfaces with opaque fallback. A full-day strip selects a two-hour detail window with evenly spaced half-hour labels. Buildings retain their historical source credit; models are original project artwork generated by `scripts/build_demo_models.py`, with no downloaded third-party model assets. Model sizes are amplified for readability and are not physical measurements. Models render above building context to stay readable; this is an illustrative selection aid, not an occlusion/visibility analysis.

## Failure and verification

Load local assets only. Missing models fall back to flat markers; missing building context is reported separately. WebGL loss hides map markers and recovery rebuilds the scene from the latest clock. A details list remains the accessible selection path. Test full-day boundaries, exact seek equivalence, weather transitions, view/layer selection, local asset requests, model failure, WebGL recovery and mobile layout. Measure the built view before considering performance acceptance. See the [walkthrough](../demos/synthetic-day.md) and [delivery plan](../delivery-plan.md).
