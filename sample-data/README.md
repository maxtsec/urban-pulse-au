# Retained public sample inputs

`sources.zip` is a reproducibility input, **not a web asset**. All data is public government schedule/geospatial material under CC BY 4.0; there are no realtime feeds, secrets or private operator records.

See [the sample walkthrough](../docs/demos/schedule-sample.md) for rebuilding, [ADR 0022](../docs/adr/0022-public-schedule-sample.md) for semantics, and the [generated manifest](../apps/web/src/assets/sample/manifest.json) for the six publisher credits, source links, receipts and modifications. `sources.lock.json` pins the archive and every member. The web Docker allowlist does not include this directory.
